This is a minimal implementation of an agent.

After you clone the repository.

Run `python -m venv .venv` in the command line within the folder.

Run `pip install -r requirements.txt` in the command line within the folder.

In the `.env` file, enter your API key after `API_KEY`, the base URL for your model after `BASE_URL`, and the model you wish to use after `MODEL`.

Finally run `python agent.py` in the command line within the folder.
